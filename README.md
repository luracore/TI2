# Nutrimax

O Nutrimax é um site que possibilita o encontro entre praticidade e saúde. A partir dos dados de clientes, o sistema sugere pratos e dietas de acordo com a necessidade de cada um. A Nutrimax conta também com uma Calculadora de IMC e um sistema de reconhecimento de alimentos através de fotos, gerando informações adicionais acerca de diversas comidas.

## Instruções de utilização

Através da barra da tela principal, podemos acessar diversas funcionalidades do site, entre elas temos o Cálculo de IMC, onde o usuário pode inserir sua altura e peso nos respectivos campos e receber o retorno de seu tipo de IMC. Entre as funcionalidades temos a manipulação de dados envolvendo alimentos: Inserir um novo alimento, retirar um alimento existente e visualizar a lista deles. Para inserção de novos ingredientes ou pratos, temos o sistema de reconhecimento de imagem. Neste, o usuário insere uma foto e recebe informações sobre a comida inserida.
